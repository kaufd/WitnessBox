# Закреплённые копии заготовки ebt/ для любого инструмента тестов
# (witnessbox scaffold generic).
#
# Формат строки: <оригинал>  <путь в клоне продукта>.
#   * kit:<путь> — файл из ресурсов установленной поставки (witnessbox --installation,
#     поле resources); так закрепляются SDK и помощники наблюдения;
#   * путь без kit: — файл рядом с ebt/ (например, obs/session.ts);
#   * абсолютный путь — внешний файл.
# Копия должна совпадать с оригиналом байт в байт. Отличие или отсутствие файла —
# причина pinned_drift и FAIL гейта, а не предупреждение.
#
# Стек generic не выбирает язык: раскомментируйте строку нужного SDK и поставьте
# путь, куда проект его кладёт. Пустой набор строк гейт принимает.
#
# kit:lib/ebt/Ebt.java   src/test/java/ebt/Ebt.java
# kit:lib/ebt/ebt.ts     src/lib/ebt/ebt.ts
# kit:lib/ebt/ebt.dart   lib/ebt/ebt.dart
#
# Помощники уровня наблюдения (D29) закрепляются так же: файл в ebt/obs/
# копируется в продукт без изменений и сверяется гейтом.
# obs/<feature>.ts  src/test/ebt/<feature>.ts
