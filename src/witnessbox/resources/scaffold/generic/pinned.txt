# Pinned copies of the ebt/ scaffold for any test tool
# (witnessbox scaffold generic).
#
# Line format: <original>  <path in the product clone>.
#   * kit:<path> — a file from the resources of the installed distribution (witnessbox --installation,
#     resources field); this is how the SDK and observation helpers are pinned;
#   * a path without kit: — a file next to ebt/ (for example, obs/session.ts);
#   * absolute path — an external file.
# The copy must match the original byte for byte. A difference or a missing file is
# a pinned_drift reason and a gate FAIL, not a warning.
#
# The generic stack does not choose a language: uncomment the line of the SDK you need and set
# the path where the project keeps it. The gate accepts an empty set of lines.
#
# kit:lib/ebt/Ebt.java   src/test/java/ebt/Ebt.java
# kit:lib/ebt/ebt.ts     src/lib/ebt/ebt.ts
# kit:lib/ebt/ebt.dart   lib/ebt/ebt.dart
#
# Observation-level helpers (D29) are pinned the same way: a file in ebt/obs/
# is copied into the product unchanged and checked by the gate.
# obs/<feature>.ts  src/test/ebt/<feature>.ts
