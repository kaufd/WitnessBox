# Закреплённые копии заготовки ebt/ для Java/Kotlin (witnessbox scaffold jvm).
#
# Формат строки: <оригинал>  <путь в клоне продукта>.
#   * kit:<путь> — файл из ресурсов установленной поставки (witnessbox --installation,
#     поле resources); так закрепляются SDK и помощники наблюдения;
#   * путь без kit: — файл рядом с ebt/ (например, obs/Sweep.java);
#   * абсолютный путь — внешний файл.
# Копия должна совпадать с оригиналом байт в байт. Отличие или отсутствие файла —
# причина pinned_drift и FAIL гейта, а не предупреждение.
#
# Ebt.java кладут только в тестовый набор исходников: в основной набор он не должен
# попадать, иначе вызовы ev() останутся в приложении (docs/sdk.md). Для Android
# путь назначения — app/src/test/java/ebt/Ebt.java.
kit:lib/ebt/Ebt.java  src/test/java/ebt/Ebt.java

# Помощники уровня наблюдения (D29) закрепляются так же; раскомментируйте и укажите
# реальные пути, когда они появятся:
# obs/<Feature>.java  src/test/java/ebt/<Feature>.java
